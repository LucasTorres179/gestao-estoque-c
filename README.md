# Inventory Management System (C)

A robust command-line interface (CLI) inventory management system developed in pure **C**, focused on structured programming, low-level memory management, and clean code practices.

## 🚀 Features

- **Product Registration:** Add new items with structured IDs, names, quantities, and prices.
- **Inventory Display:** List all active records cleanly formatted in the terminal.
- **Record Updating:** Modify existing product attributes securely.
- **Logical Deletion:** Safely remove items from the active inventory list.
- **Buffer & Flow Control:** Robust handling of standard input (`stdin`) to prevent buffer overflow and infinite loops during menu navigation.

## 🛠️ Technologies & Concepts Applied

- **Language:** C (Standard C99+)
- **Data Structures:** Custom `structs` and static arrays for memory storage.
- **Memory Management:** Pointers (`*p`) and pass-by-reference for efficient data manipulation.
- **Control Flow:** `do-while` loops, `switch-case` blocks, and modular subroutines.
- **Version Control:** Git & GitHub.
